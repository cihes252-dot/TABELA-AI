# TABELA AI

AI destekli tabela saha tarama uygulaması.

## Hedef
- Tabela algılama
- Otomatik OCR
- GPS kayıt
- Fotoğraf / video
- Gerçek AR/Depth ölçüm altyapısı
- Tekrar tabela kontrolü
- Harita ve raporlama
- Android APK ve iOS TestFlight paketleri için ortak proje

## V1
Şimdiki GitHub Pages sürümü mobil PWA saha uygulamasıdır. Kamera, GPS, fotoğraf, proje/kayıt yönetimi ve CSV dışa aktarımını içerir. iPhone 11'de LiDAR olmadığı için doğrulanmamış genişlik/yükseklik/m² üretilmez.
